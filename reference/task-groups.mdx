Task groups are defined in [`task-groups.yaml`](https://github.com/OpenEuroLLM/oellm-eval/blob/main/oellm/resources/task-groups.yaml). **Evals** is the number of evaluations per model; **Metric** is what `collect` reports (_all_ = every metric is kept).

## Super groups

| Name | Contains | Evals |
| --- | --- | --- |
| `multilingual-oellm-eu` | Every multilingual benchmark in the 36 OpenEuroLLM languages (groups marked ★) | 401 |
| `oellm-multilingual` | FLORES (both directions), Belebele 5-shot, Global-MMLU, MGSM, generic-multilingual, INCLUDE, MultiBLIMP, XCOPA | 173 |
| `all` | Every group; use it with a language filter, e.g. `all[deu_Latn]` | – |

## English groups

**`dclm-core-22`** (22 evals, default metric `acc`). Needs a [special environment](/installation#special-environments) outside LUMI.

| Shots | Tasks |
| --- | --- |
| 0 | `copa`, `openbookqa`_, `hellaswag`_, `winogrande`, `wsc273`, `lambada_openai`, `coqa` (f1) |
| 3 | `agieval_lsat_ar` |
| 10 | `arc_easy`_, `arc_challenge`_, `boolq`, `commonsense_qa`, `hellaswag`_, `piqa`_, `bigbench_language_identification_multiple_choice`, `squadv2` (f1), `jeopardy` (exact_match), 5 BIG-bench `*_generate_until` tasks (exact_match) |

\* scored with `acc_norm`.

**`open-sci-0.01`** (12 evals): `copa`, `social_iqa`, `openbookqa`, `lambada_openai`, `winogrande` (0-shot); `mmlu` (5-shot); `hellaswag`, `arc_easy`, `arc_challenge`, `commonsense_qa`, `piqa`, `boolq` (10-shot).

**`crows-pairs`** (1 eval, 0-shot, metric `pct_stereotype`): the CrowS-Pairs social bias benchmark in English.

## Reasoning

**`reasoning`** (10 evals, all metrics kept). GSM8K (4-shot), IFEval (0) and MBPP (3) run on lm-eval; GPQA-Diamond, MATH500, LiveCodeBench, HumanEval, AIME24, AIME25 and AMC23 (0-shot) run on evalchemy. Needs a [special environment](/installation#special-environments).

**`gpqa-diamond`** (2 evals, lighteval, 0-shot, metric `gpqa_pass@k:k=1`): GPQA Diamond answered by free generation, in English ([Idavidrein/gpqa](https://huggingface.co/datasets/Idavidrein/gpqa), gated) and Finnish ([LumiOpen/GPQA-FI](https://huggingface.co/datasets/LumiOpen/GPQA-FI)). Answers can run to 32,768 tokens, so it needs a small batch size; see [GPU memory](/guides/running-evaluations#gpu-memory). Pick one language with `gpqa-diamond[fin_Latn]`.

## LLM judge (JudgeArena)

These groups run on [JudgeArena](https://github.com/OpenEuroLLM/JudgeArena) and need a judge model; see [LLM-judge benchmarks](/guides/running-evaluations#llm-judge-benchmarks). All are 0-shot, and `collect` keeps every numeric metric JudgeArena reports.

| Group | Contains | Evals |
| --- | --- | --- |
| `judgearena` | Super group of `judgearena-default`: AlpacaEval, Arena-Hard v0.1 and v2.0, m-ArenaHard v0.1 and v2.0, MT-Bench, fluency, and the ComparIA and LMArena ELO tasks | 11 |
| `elo-en` | ComparIA and LMArena ELO tasks in English | 4 |
| `elo-eu` | ComparIA and LMArena ELO tasks in the supported European languages | 32 |
| `elo-multilingual` | Super group of `judgearena-comparia` (2) and `judgearena-lmarena` (51): every ELO language variant | 53 |
| `judgearena-m-arena-hard` | m-ArenaHard v0.1 and v2.0 in 23 languages | 46 |
| `judgearena-fluency` | Fluency in 43 languages | 43 |
| `judgearena-additional` | MT-Bench-101, and the EU subsets of m-ArenaHard v0.1 and v2.0 | 3 |
