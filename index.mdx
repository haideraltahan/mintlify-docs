**oellm-eval** is the OpenEuroLLM evaluation tool. Give it a model and a set of benchmarks; it downloads what's needed, submits the work to SLURM, and collects the scores into one CSV.

```bash
oellm-eval schedule --models "EleutherAI/pythia-160m" --task_groups "open-sci-0.01"
oellm-eval collect  --results_dir <printed run directory> --output_csv results.csv
```

## Design

| Feature | How it works |
| --- | --- |
| **Task groups** | One name expands into many evaluations. `multilingual-oellm-eu` alone is 401. |
| **Offline-first** | Models and datasets are downloaded on the login node; GPU jobs never need the internet. |
| **Cluster presets** | LUMI, Leonardo, JURECA, Jupiter and Snellius are detected automatically, with partition, account and output folder filled in. |
| **Several harnesses** | [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness) and [lighteval](https://github.com/huggingface/lighteval), plus [evalchemy](https://github.com/mlfoundations/evalchemy) for reasoning and [JudgeArena](https://github.com/OpenEuroLLM/JudgeArena) for LLM-judge benchmarks. Each task uses the right one. |
| **Language filters** | `multilingual-oellm-eu[deu_Latn]` runs every multilingual benchmark that has German. |
| **Resumable** | `collect --check true` writes the unfinished evaluations to a CSV you can re-submit. |

## Quick examples

```bash
# Full multilingual suite: 401 evaluations, 36 languages
oellm-eval schedule --models "my-org/my-model" --task_groups "multilingual-oellm-eu"

# One language across every multilingual benchmark
oellm-eval schedule --models "my-org/my-model" --task_groups "multilingual-oellm-eu[deu_Latn]"

# English core benchmarks
oellm-eval schedule --models "my-org/my-model" --task_groups "dclm-core-22"

# Every checkpoint in a training output folder
oellm-eval schedule --models "/scratch/my-run/checkpoints" --task_groups "open-sci-0.01"
```

<Note>
  On LUMI, add `--venv_path /scratch/project_465002530/venvs/oellm-eval-rocm` to every `schedule` command. See [Cluster Scheduling](/guides/cluster-scheduling#lumi).
</Note>
